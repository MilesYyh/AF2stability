# 6.plot_ddg_scatter.py

## Role in the pipeline

This script turns the per-sample prediction outputs from `5.train_ddg_mlp.py` into **predicted-vs-experimental ΔΔG scatter plots**, styled to resemble the paper's Fig 1C style of presentation.

It is the main figure-generation script for the core ddG regression visualization.

## Inputs

- `results/models/ddg_mlp_full_partial_holdout_predictions.csv`
- `results/models/ddg_mlp_full_partial_holdout_summary.json`
- `results/models/ddg_mlp_full_partial_cv10_predictions.csv`
- `results/models/ddg_mlp_full_partial_cv10_summary.json`

## Outputs

- `results/figures/ddg/holdout_predicted_vs_experimental_ddg.png`
- `results/figures/ddg/cv10_predicted_vs_experimental_ddg.png`

## Code structure

The script is organized into:

- `resolve_repo_path()` for path resolution
- `load_predictions()` for loading prediction CSVs and filtering by split
- `load_summary()` for reading summary metrics used in titles
- `add_identity_line()` for the `y=x` guide line
- `make_scatter_plot()` for the actual plotting logic
- `main()` for orchestrating the holdout and CV figures

## What the plots show

### Holdout figure

- uses only the holdout `val` samples
- x-axis: experimental ΔΔG
- y-axis: predicted ΔΔG
- subtitle includes Pearson, MAE, and RMSE

### CV10 figure

- uses all random 10-fold CV `val` samples
- each point is still experimental vs predicted ΔΔG
- points are colored by `fold_index`

### Reference line

Both plots include a `y=x` identity line for visual calibration.

## How to run it

```bash
python scripts/6.plot_ddg_scatter.py
```

You can also override paths explicitly.

## Best use cases

- producing a paper-like engineering scatter figure
- checking whether the model captures a broad trend rather than a few influential points
- seeing whether different CV folds behave differently

## Common pitfalls

- if `5.train_ddg_mlp.py` was not run with `--predictions-csv`, there will be no per-sample predictions to plot
- the script intentionally plots only validation samples, not training samples, because generalization is the more meaningful view
