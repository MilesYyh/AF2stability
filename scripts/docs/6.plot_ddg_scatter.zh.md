# 6.plot_ddg_scatter.py

## 脚本定位

这个脚本负责把 `5.train_ddg_mlp.py` 导出的逐样本预测结果画成 **predicted vs experimental ΔΔG 散点图**，风格上尽量接近论文中 Fig 1C 那类“预测值对实验值”的展示方式。

它是当前结果展示层的主图脚本。

## 输入

- `results/models/ddg_mlp_full_partial_holdout_predictions.csv`
- `results/models/ddg_mlp_full_partial_holdout_summary.json`
- `results/models/ddg_mlp_full_partial_cv10_predictions.csv`
- `results/models/ddg_mlp_full_partial_cv10_summary.json`

## 输出

- `results/figures/ddg/holdout_predicted_vs_experimental_ddg.png`
- `results/figures/ddg/cv10_predicted_vs_experimental_ddg.png`

## 代码结构

这个脚本分成几层：

- `resolve_repo_path()`：统一路径解析
- `load_predictions()`：读取预测 CSV，并按 `split` 过滤（主要画 `val`）
- `load_summary()`：读取 summary JSON，提取标题里要显示的指标
- `add_identity_line()`：加 `y=x` 参考线
- `make_scatter_plot()`：真正负责画图
- `main()`：编排 holdout 和 cv10 两张图的生成

## 图是怎么画的

### holdout 图

- 只取 holdout 的 `val` 样本
- x 轴：experimental ΔΔG
- y 轴：predicted ΔΔG
- 标题里写入 Pearson / MAE / RMSE

### cv10 图

- 取 random 10-fold CV 的所有 `val` 样本
- 每个点仍然是 `experimental` vs `predicted`
- 用 `fold_index` 上色，体现 10 个 fold 的来源

### 参考线

会额外画一条 `y=x` 参考线，帮助直观看偏差。

## 如何运行

```bash
python scripts/6.plot_ddg_scatter.py
```

也可以显式传入输入输出路径。

## 适合拿来做什么

- 做最接近论文 Fig 1C 的工程版散点图
- 直观看模型是在整体趋势上相关，还是只是少数点拉高 Pearson
- 检查不同 fold 是否有系统偏差

## 常见坑

- 如果没有先让 `5.train_ddg_mlp.py` 用 `--predictions-csv` 导出逐样本预测，这个脚本就没有输入可画
- 当前图只画 `val` 样本，不画 train 样本，这是有意为之，因为展示泛化更重要
